Transforming DLC outputs

Run the videos in DLC! Generate the videos and have a quick look - make sure that the tracking is looking good.
Common issues include: tracking because the camera angle is too tilted, or there is too much junk around the bottoms. You might have to crop the video dimensions. 


Run the Refpoints_cage_v1-Pieter-2024-03-18 DLC file (or any other to get the coordinates of the arena) to get the coordinates of the box. 
- you can collapse the reference coordinates outputs from labelling each video using 'reference_file.py', since the coordinates are saved as csv files in subfolders


Make a transformation matrix from MATLAB using the fitgeom2form function on the arena coordinates. Convert it from pixels to cm based on your inputs to the MATLAB function. For videos from the FSCV box using the model generated by George+Pieter, use the 'generate_tform_matrices' MATLAB file.


Transform the datapoints of the transformation matrix using the 'DLC_transformation.py' file. This will transform the coordinates into the specified dimensions and units. 


OPTIONAL: To have a quick look at the data, run the 'DLC_plotsess.ipynb' file. You can see the tracking of various body parts for the whole session here. 


Generate trigger files. These denote the video frames where your trial starts. There should be a column called "VideoFrame" as the script will search for these, for each animal.

Run the filtering method using 'preprocess_DLC.py' 

Create trigger info files: this will depend on your scripts and how you want to lay it out.

Specific to Go/Nogo:
- Run the PlotDLC.ipynb function to visualise and check the alignments of your trials.
